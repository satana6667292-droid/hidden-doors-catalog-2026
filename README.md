# Hidden Doors — Catalog 2026 Web

Первый веб-мастер каталога Hidden Doors 2026.

## Что уже работает
- просмотр обложки отдельно и каталога разворотами;
- мобильный режим — по одной странице;
- список всех 44 страниц и фильтр по статусу;
- служебный режим редактора;
- изменение названия и статуса страницы;
- фиксация согласованных страниц;
- настройка «разворот со следующей страницей»;
- перестановка страниц drag & drop;
- локальное сохранение структуры в браузере (localStorage);
- согласованные макеты перенесены без перерисовки — как исходные изображения страниц.

## Следующие этапы

2. Добавить авторизацию администратора.
3. Для страниц «В работе» постепенно заменить растр на редактируемые HTML-блоки.
4. Добавить загрузку/замену изображения страницы через админку.
5. Добавить генерацию PDF из утверждённой веб-структуры.
6. Развернуть staging и после проверки привязать финальный домен.

## Локальный запуск
Откройте `index.html` напрямую или запустите любой статический сервер, например:

```bash
python3 -m http.server 8080
```
